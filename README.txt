AV UNITED ESPORTS WEBSITE

FILES
- index.html: complete responsive website
- assets/images/: the player portraits and gallery images you sent
- assets/audio/: the four voice-pack audio files used by the website

PREVIEW
Open index.html in a modern browser. Keep the assets folder beside index.html.

PUBLISH ONLINE (GitHub Pages)
1. Sign in to GitHub and create a new public repository, for example av-united-esports.
2. Upload index.html and the complete assets folder (including its subfolders).
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub to publish the site. The shareable URL will appear in Settings > Pages.

NOTES
- Audio files are wired to the voice cards in the requested order: Zelta, Fighter OP, Matrix, IGL Bolte.
- IGL Bolte currently uses the same uploaded audio file as Zelta because the uploads include a duplicate file. Replace assets/audio/igl-bolte.mp3 if you have a separate IGL Bolte recording.
- Player details shown are limited to names/roles provided in the chat; update index.html if you want to add more confirmed stats.
